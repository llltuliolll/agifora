Sobre o AgiFora

Transparência e justiça financeira para o consumidor brasileiro

O que é o AgiFora?

O AgiFora é uma aplicação web desenvolvida para auditar cálculos de parcelamento e empréstimos, identificando automaticamente cobranças abusivas e violações legais em negócios informais ou varejistas.

A ferramenta calcula o Custo Efetivo Total (CET) de qualquer operação de crédito e compara com os limites estabelecidos pela Lei de Usura (Decreto nº 22.626/33), que proíbe taxas superiores a 1% ao mês (12% ao ano) para entidades que não fazem parte do Sistema Financeiro Nacional.

Base Legal
  • Decreto nº 22.626/33 — Lei de Usura: proíbe juros superiores a 12% a.a.
  • Lei nº 8.078/90 — Código de Defesa do Consumidor: exige transparência nas relações de consumo.
  • Constituição Federal/1988 — Art. 5º: direitos do consumidor como direito fundamental.
Tecnologias Utilizadas
  • Backend: Python 3.12 + Django 5.1
  • Cálculos: NumPy Financial (TIR/IRR)
  • Banco de dados: PostgreSQL
  • Frontend: Bootstrap 5, HTML5, CSS3, JavaScript
Como o CET é calculado?

O Custo Efetivo Total é calculado pela Taxa Interna de Retorno (TIR) do fluxo de caixa da operação: o valor à vista é tratado como entrada (positiva) e cada parcela como saída (negativa). A TIR resultante representa exatamente a taxa de juros embutida na operação — independente de como o comerciante apresenta o preço.

Fórmula: Valor_a_vista = Σ Parcelai / (1 + CET)i
Resolvemos para CET usando o algoritmo numérico Newton-Raphson via numpy_financial.irr().
